# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：肾癌（透明细胞癌/乳头状/嫌色/集合管等）患者与照护者双主体；覆盖确诊与分型、保肾或根治手术、消融、主动监测、晚期靶向与免疫治疗、术后复查全程；支持代记与私密内容分级

场景：患者与照护者整理病理与分型、手术记录、肌酐/eGFR 与尿蛋白等周期化验、CT/MRI/超声影像与结节大小、靶向与免疫治疗方案与线序、血压与甲功等副作用相关指标、复诊问题，追踪主动监测与术后随访节奏，准备就诊材料并回顾医生确认后的记录

核心流程：
1. 选择本地资料目录并导入或登记病理分型、手术与影像、化验、用药材料
2. 核对分型与手术档案（引用不判定）、Cr/eGFR 趋势、主动监测大小记录、治疗线序与副作用记录
3. 查看术后随访与主动监测时间轴，标记症状与待办，生成复诊摘要与问题清单
4. 照护者以代记身份记录随访与照护线索，私密内容分级管理，并把明确任务交给 Desktop 原生 Agent 会话

完成结果：患者与照护者确认的资料和随访时间轴、可追溯的肾功能与结节大小记录、治疗线序与副作用记录、复诊摘要均保存在明确选择的本机资料目录中；私密内容按 visibility 分级且三处出口过滤

初始布局选择：business-first
