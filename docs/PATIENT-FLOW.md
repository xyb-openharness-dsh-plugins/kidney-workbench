# 患者流程（PATIENT-FLOW）· 肾癌 v0.1

> 三条路径都由「患者在什么时刻最难受」反推页面树，不从医生流程照搬。
> 场景均为假设，标〔待访谈核实〕；H1–H6 见 USER-RESEARCH。

## 路径 A · 一次真实就诊（晚期，靶免治疗中）〔待访谈核实〕

```
周三下午复诊前夜，患者想把这三周的事说清楚，但记不得哪周开始手脚脱皮、
血压哪天长到 150、上次医生说的「下次 6 周后复查」是几号。
```

1. **打开看板** → 「今日一页」显示：当前治疗方案、距下次复查天数、最近一次血压/甲功值。
2. **进「用药与副作用 → 副作用记录」** → 按日期补三条：手脚皮肤反应、腹泻、乏力；
   每条可并一张同日血压（不自动并轴，用户自己看到）。
3. **进「随访与复诊 → 问题清单」** → 勾选想问的：「手脚脱皮要不要减量」「血压药要不要调」——
   产品只把用户勾选的问题整理成清单，**不生成答案**。
4. **进「随访与复诊 → 复诊摘要」** → 一页导出：线序、最近化验、副作用记录、问题清单。
   **产物**：明天能带进诊室的一页纸。

## 路径 B · 一次自查（术后第一年，Cr 有点高）〔待访谈核实〕

```
术后半年复查前，患者看到化验单上肌酐比术前高，想知道「是不是肾不够用了」，
但工作台不能回答这个问题——它只能把数字放回位置。
```

1. **打开看板** → 肾功能指标卡显示 Cr 最新值与参考区间（对照，不判读）。
2. **进「手术与肾功能 → 肾功能趋势」** → 一图秀：术前基线点 → 术后 1 月 → 3 月 → 6 月；
   曲线上叠加手术事件竖线。**没有「下降/恶化」字样，没有斜率评语。**
3. **进「化验与指标 → 参考范围」** → 这张化验单自带的参考区间原文（缺了就显示「未引入」）。
4. **进「随访与复诊 → 问题清单」** → 「肌酐比术前高，要不要紧？」——出口是问医生。
   **产物**：一条趋势线 + 一个问医生的问题。

## 路径 C · 一次复查（主动监测，小结节）〔待访谈核实〕

```
体检发现 2.8cm 肾肿块，医生说要「先看看」。三个月后该拍片了，
患者想知道上次多大、这次该做什么，但不敢自己算长快了没有。
```

1. **打开看板** → AS 路径卡片：上次影像日期、大小原文、距下次节点（按自己记录的节奏推算）。
2. **进「主动监测 → 影像与大小」** → 时间轴：每次影像的日期、方式（CT/MRI/超声）、
   大小原文 mm。**并列摆放，不连线成「生长曲线」，不标 mm/年。**
3. **进「主动监测 → 监测节奏」** → CSCO 2025 §7 密切监测（T1a）原文引用：
   「开始前 2 年每 3 个月 1 次，然后每 6 个月 1 次，5 年后每年 1 次」（机构+版本+小节，页码待核）。
4. **复查后回「影像与大小」** → 新增一行，旧行不动（更正只新增版本）。
   **产物**：一条并列记录 + 「下次大约什么时候」的参考节点。

## 页面树反推

| 一级页 | 由哪条路径反推 | 不建会怎样 |
| --- | --- | --- |
| 看板 | A/B/C 都要 | 每次都要从头翻 |
| 我的瘤与分型 | B/C（报告看不懂） | 分型分期分级三个词混在一起 |
| 手术与肾功能 | B | 术后 Cr 趋势无处放 |
| 主动监测 | C | AS 患者只剩「记不住」 |
| 治疗与线序 | A | 晚期说不清用过哪些方案 |
| 用药与副作用 | A | 副作用只散在记忆里 |
| 化验与指标 | B | 单点数值没有位置 |
| 影像与报告 | B/C | 影像报告原文丢了 |
| 随访与复诊 | A/B/C | 节奏与问题清单无处生成 |
| 生活与照护 | A/B/C | 饮食体重情绪出行无处放 |
