## 二、照抄样板的产品要求（不许按比例缩减）

- **顶栏三段式**：品牌 + 页面导航 + AI 五态按钮（`AI 对话 / 正在连接… / 收起 AI 对话 / 打开 AI 对话 / AI 对话暂不可用`）+ 独立「×」；面板内部不放第二组开合控件。
- **AI 面板默认右侧**：`businessWidth: 0.65` / `AGENT_PANE.default: 0.35` 互补，`assertPanelConfig()` 钉住；可拖（容器 rect 夹取、role=separator、键盘同精度、localStorage 读回过 clamp）；窄容器（<760px）覆盖式抽屉 ≤420px，splitter 不出现。
  原型落地范围（2026-10-24）：开合、三档宽度按钮（窄 / 标准 / 宽）、窄宽覆盖态已有；**拖拽分隔条、键盘精度、localStorage 读回属开发版（M6）**——原型不挂真 layout 引擎，拖拽无法验证 clamp 真实性。
- **一图秀**：单调三次插值、末点 13px 避让、事件竖虚线止于 CY0-10、分类序列只画节点不连线。
- **3D 卡**：整卡 180°、背面迷你折线、分类记录不翻不连线。
- **字号三档**：`--tz` 1 / 1.15 / 1.32；`calc(NNpx * var(--tz))`；SVG 文字不随档位；溢出判 `body.scrollWidth`。
  原型落地范围（2026-10-24）：顶栏按钮做三态循环（正常 / 大字 / 特大），切 body 基础层 `--font:calc(15px * 1.15/1.32)`；
  **组件级 `calc(NNpx * var(--tz))` 乘法体系属开发版（M6）**——原型组件字号是逐页调优的固定 px，随档位整体缩放会打破逐页调优的版式。
- **根节点首个子元素必须是语义 `<header>`**，避让 `--dsh-frame-leading-clearance`。

## 三、硬约束（四组，每条带错误来源）

### 3.1 数据层

1. 复合主键表裸 `SELECT` 必须 `ORDER BY rowid`（gastric/attr 踩过：metrics 是 `(profile_key, key)` 复合主键）。
2. 手写倒序数组只 `ORDER BY ord` 不叠 `DESC`。
3. 可选字段显式写 `null`，读模型按 `=== null` 分支；**空 ≠ 阴性**——「没记」与「没有」在库里必须能分开。
4. `using` 是 SQLite 保留字 → 列名 `in_use`。
5. 每一节 `{title, rows}` 都要有对应 `*_title` 列（gastric 教训：发布前才发现漏列，走 ALTER 追加）。
6. 化验记录必须有 `ref_low` / `ref_high` 两列（可空）；写入校验：**先挡 `null/undefined/''` 再 `Number()`**——`Number(null)===0` 会把「没填上限」变成「上限是 0」（本项目族三个地方踩过）。
7. 影像/内镜按真实频率**不加密**；化验/体征 2–4 周一点延续到今天。
8. `events` 无 `ord` 列，读取按 `rowid` 升序；其余多行表按 `ord`。

### 3.2 前端

9. 图标 key 走别名兜底；内联 svg 必须给宽高。
10. 页脚贴底：`min-height:calc(100vh - 32px)` + `flex:1`；`[hidden]{display:none!important}`。
11. 二级页签按 `state.sub` 分流且**穷举测试**。
12. 字号基线 12.5px（大字 15px）。
13. `data-dev-only` 与 `<!--dev-only-->` 只用于「原型冻结、开发版先行」，`test/ui-parity.test.mjs` 的 WHITELIST 逐条写明理由。

### 3.3 工程

14. 面板参数唯一来源 `lib/layout.js`；客户端里不许出现第二个 `0.65` / `0.35`。
15. `apiBase` 不含 `/api`；页面统一拼 `${API_BASE}/api/xxx`；守卫只禁交界重复 `/api/api`，**不许 `includes('/api')` 一刀切**（GBM 踩 4）。
16. 演示数据只有一个来源；`lib/version.js` 是生成物不手改。
17. 迁移只增不改；所有 INSERT 写显式列名 + 显式问号数。
18. 启动期校验失败**渲染错误横幅，禁止裸 throw 白屏**。

### 3.4 医学口径（四条，starter `docs/23` / `docs/25`）

19. **分级只用「对照」**：不写「偏高/偏低/严重」，不推断因果、不给处置。
20. **×ULN 型必须用这张化验单自带的 `ref_high`**，缺了返回 `needsUln`，绝不拿成人通用上限凑倍数（「下限可以借，上限不能借」）。
21. **指南只做「出处 + 节奏 + 并列口径」**：处置推荐只折叠原文，不改写成产品语句；**不出现「所以/因此/你需要」**。
22. **未采用的原文分支**要在注释里写明「未采用」及原因，不是漏做。
23. **肾癌专属两条**：① IMDC 六项只引用原文，产品不打分，界面写明「预后模型不是预测工具」；② AS 影像大小只并列，**不算生长速度、不设「该手术了」阈值**。
24. **提醒只来自用户自己的记录或日期**，不来自医学阈值（见 SCENARIOS「提醒边界」）。

## 四、本轮明确未做（不许在验收里算通过）

- 装机（V2/V3 真机）、市场投稿、`gh release`。
- 患者/家属访谈——六条假设全悬空，场景清单不得当已确认需求。
- 中文指南原件取得（CSCO 2025 目前只有公开摘录，页码待核）。
- 中国获批药物清单逐条核实（NCCN/EAU 列的不等于中国获批）。
- ChiCTR 离线语料（只有胰腺癌）；肾癌只能走在线通道。
- 真实病例、任何医学结论。
- **照护者代记**：「生活与照护」页只有照护者留言位（代记内容 + 私密分级说明），**没有**照护者独立身份、登录、权限分级——属 M6 范围，G1 范围外。
- **AI 面板拖拽**：三档宽度按钮有，拖拽分隔条 / 键盘同精度 / localStorage 读回未做（见 §二 注解）。
